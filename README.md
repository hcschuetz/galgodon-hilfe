README
======

Ein Helfer für "Galgodon", das Galgenmännchen-Spiel auf Mastodon bzw.
im Fediverse.

Die Idee der Berechnung des teilweise aufgedeckten Suchbegriffs
wurde von https://github.com/jesterchen/galgenmasto/ übernommen.
Während das jedoch eine Kommandozeilen-Lösung ist,
ist die hier vorliegende Lösung eine Web-Applikation mit GUI
(https://hcschuetz.github.io/galgodon-hilfe/).
Darüber hinaus bietet diese Seite mittlerweile auch Unterstützung bei der
Erstellung von Umfragen.
